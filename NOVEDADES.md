## Versión 1.1.0

**La app viene compilada para Windows, Linux y Mac:** se baja el .zip de tu sistema, se descomprime y se abre
el programa `EdificiosDeMama` (en Windows, `EdificiosDeMama.exe`). No hace falta instalar Python. Al abrirlo arranca
la app y se abre el navegador solo. Cerrar la ventana negra apaga la app. Los datos quedan en la carpeta `data`, al lado del programa.

- `edificiosDeMama-v1.1.0-windows.zip`: Windows.
- `edificiosDeMama-v1.1.0-linux.zip`: Linux.
- `edificiosDeMama-v1.1.0-macos.zip`: Mac (la primera vez: clic derecho > Abrir, porque el programa no está firmado por Apple).
- `edificiosDeMama-v1.1.0.zip`: el código fuente, con lanzadores de doble clic (`iniciar.bat`, `iniciar.command`, `iniciar.sh`) para quien tenga Python.

Novedades:
- Versiones compiladas para los tres sistemas, que también se actualizan solas.
- Lanzadores para usar la app desde el código fuente en Windows, Linux y Mac.
- Si la app ya está abierta, abrirla de nuevo solo abre el navegador.
